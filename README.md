# TrackPlanRanker
TrackPlanRanker is a Flask-based web application built for athletes who sometimes question if they’re doing the right thing.

Athletes can input their current weekly training plan, and the system will analyse and rank it using AI-informed sprint principles.

The app evaluates:
- Training effectiveness  
- Recovery balance  
- Periodisation structure  
- Loading vs deloading  
- Event-specific feedback (100m, 200m, 400m)

This project was created with one core idea in mind:

A lot of athletes overthink their training.  
We wonder if we’re doing too much.  
Too little.  
If the coach’s plan is right.  
If we’re falling behind.

TrackPlanRanker aims to provide reassurance and clarity — helping athletes feel confident that their training structure supports their long-term goals.

It’s not here to replace coaches.  
It’s here to support athletes.
