# TrackPlanRanker
TrackPlanRanker is a Flask-based web application that allows athletes to input their weekly training schedules and receive AI-powered feedback.

The system evaluates:
- Training intensity balance
- Recovery and rest distribution
- Event alignment (100m / 200m / 400m)
- Overall plan effectiveness

The goal is to help athletes optimise performance while reducing overtraining risk.

---

## Tech Stack
- Python 3.12
- Flask
- HTML/CSS

---
